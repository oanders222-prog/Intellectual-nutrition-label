# Intellectual Nutrition Label site

Static multi-page site for GitHub and Vercel.

## Pages

- `index.html` — homepage
- `about.html` — About page with editable text area
- `labels.html` — blog-style label index
- `contact.html` — Contact page with editable text area
- `sample-label.html` — sample individual label page

## Adding a new label

1. Add the label image to `assets/`.
2. Copy `sample-label.html` and rename it, for example `professor-smith.html`.
3. Edit the new page.
4. Add a new card near the top of `labels.html` linking to the new page.
